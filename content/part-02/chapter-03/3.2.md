# 3.2 ควรเริ่มกี่ตัว

> **สรุปสั้น:** ไม่มีจำนวนสุกรที่ดีที่สุดสำหรับทุกฟาร์ม จำนวนเริ่มต้นควรต่ำกว่าความสามารถสูงสุดที่ยังไม่เคยทดสอบ และต้องสอดคล้องกับทุน แรงงาน ที่ดิน น้ำ อาหาร ตลาด biosecurity ของเสีย และความสามารถของเจ้าของในการเห็นและแก้ปัญหาทุกวัน

## อย่าเริ่มจากคำตอบเป็นตัวเลข

คำถาม “ควรเริ่มกี่ตัว” มักถูกถามก่อนคำถามที่สำคัญกว่า เช่น ใครจะดูแล น้ำพอหรือไม่ มีตลาดรับซื้อหรือยัง และถ้าเกิดเหตุผิดปกติจะจัดการอย่างไร จำนวนสุกรจึงไม่ใช่ตัวแปรเดี่ยว แต่เป็นผลจากความจุของระบบทั้งหมด

มกษ. 6403-2565 ครอบคลุมองค์ประกอบฟาร์ม การจัดการ บุคลากร สุขภาพ สวัสดิภาพ สิ่งแวดล้อม และการบันทึกข้อมูล [1] จำนวนเริ่มต้นที่เหมาะสมต้องทำให้ทุกองค์ประกอบเหล่านี้ทำงานได้ ไม่ใช่เพียงทำให้มีพื้นที่คอกว่างพอ

## Capacity ไม่ใช่พื้นที่คอกอย่างเดียว

ให้คิด capacity เป็นคอขวดที่เล็กที่สุดของระบบ หากโรงเรือนรองรับได้มากแต่น้ำสำรองไม่พอ ระบบไฟฟ้าไม่มีแผนฉุกเฉิน หรือคนดูแลตรวจสุกรไม่ทั่วถึง จำนวนที่มากขึ้นก็ไม่ได้แปลว่าผลผลิตดีขึ้น

| ด้าน | สิ่งที่ต้องตอบก่อนเพิ่มจำนวน |
|---|---|
| ทุน | จ่ายค่าซื้อสุกร อาหาร วัสดุ และเหตุฉุกเฉินได้โดยไม่ขาดเงินสดหรือไม่ |
| แรงงาน | มีคนทำงานประจำและคนแทนในวันหยุดหรือไม่ |
| ที่ดิน/โรงเรือน | แยกพื้นที่ รับสุกรใหม่ และทำความสะอาดได้หรือไม่ |
| น้ำ/ไฟฟ้า | มีน้ำสะอาดและระบบสำรองเมื่อปั๊มหรือไฟฟ้าขัดข้องหรือไม่ |
| อาหาร | มีแหล่งอาหารและพื้นที่เก็บที่ป้องกันความชื้น เชื้อรา และสัตว์พาหะหรือไม่ |
| สุขภาพ | มีแผนรับสุกรใหม่ ควบคุมคน/รถ และสัตวแพทย์ผู้รับผิดชอบหรือไม่ |
| ของเสีย | รองรับมูล น้ำล้าง ซาก และกลิ่นได้โดยไม่สร้างปัญหาชุมชนหรือไม่ |
| ตลาด | มีผู้ซื้อ เงื่อนไขคุณภาพ และแผนขนส่งที่ตรวจสอบได้หรือไม่ |
| ความสามารถจัดการ | เจ้าของตรวจพบความผิดปกติและตัดสินใจได้ทันหรือไม่ |

## เริ่มแบบเป็นระยะ

การเริ่มแบบเป็นระยะช่วยให้ทดสอบการให้อาหาร การล้างคอก การบันทึก การเข้าออก และการขายจริงก่อนขยาย แต่ “เริ่มน้อย” ไม่ได้แปลว่าไม่ต้องมีระบบสุขภาพหรือของเสีย มกอช. ระบุองค์ประกอบและการจัดการที่ฟาร์มต้องคำนึงถึงตั้งแต่ต้น [2]

**Recommendation:** แบ่งการขยายเป็น gate เช่น ทดลองระบบเปล่า ตรวจสาธารณูปโภค รับสัตว์ตามจำนวนที่คนดูแลได้ สรุปผลรอบแรก แล้วจึงพิจารณาขยาย หากมีข้อผิดพลาดที่ยังไม่แก้ ให้หยุดที่จำนวนเดิมแทนการเพิ่มเพื่อหวังชดเชยต้นทุน

## จำนวนมากขึ้นเพิ่มทั้งโอกาสและความเสี่ยง

ฝูงที่ใหญ่ขึ้นอาจช่วยให้ใช้แรงงานหรืออุปกรณ์บางอย่างได้คุ้มขึ้น แต่ก็เพิ่มปริมาณอาหาร น้ำ มูล การเคลื่อนย้าย การบันทึก และจุดที่โรคหรือปัญหาการจัดการอาจแพร่ภายในระบบ งานทบทวนด้าน biosecurity แยกการป้องกันความเสี่ยงจากภายนอกและการควบคุมการแพร่ภายใน [3] [4] จึงไม่ควรใช้ “ขนาดใหญ่” เป็นคำตอบแทนการออกแบบ biosecurity

การมีคนมากขึ้นก็ไม่ได้รับรองว่าดูแลดีขึ้น หากไม่มีหน้าที่ชัดเจน วิธีทำงานเดียวกัน และการตรวจความครบถ้วน จำนวนคนต้องประเมินร่วมกับทักษะ ระยะทางในฟาร์ม ระบบอัตโนมัติ และเวลาที่ต้องใช้ต่อวัน

## เชื่อมจำนวนกับตลาดและรอบเงินสด

จำนวนสุกรที่เริ่มควรสัมพันธ์กับจำนวนที่ผู้ซื้อรับ เงื่อนไขน้ำหนัก/คุณภาพ ตารางขนส่ง และเงินสดที่จมอยู่ในอาหารและสัตว์ หากผลิตมากกว่าตลาดรองรับ ปัญหาจะกลายเป็นระยะเลี้ยงยาวขึ้น พื้นที่คับแคบ หรือขายเร่งด่วน

รายละเอียดราคาปัจจุบันและทุนหมุนเวียนอยู่ในหัวข้อ 3.9–3.10 จึงไม่ใส่ราคาในหัวข้อนี้ ตัวอย่างใด ๆ ที่จะคำนวณจำนวนหรือเงินต้องติดป้าย **EXAMPLE_ONLY** และห้ามอ่านเป็นประมาณการของฟาร์มจริง

## EXAMPLE_ONLY: คิดจากคอขวด

สมมติว่าเจ้าของกำหนดให้ “ความสามารถตรวจสุกรและจัดการอาหารในวันที่ไม่มีคนแทน” เป็นคอขวด แล้วทดลองระบบในจำนวนหนึ่งโดยไม่ใช้ตัวเลขนี้เป็น benchmark เมื่อพบว่าการตรวจ การบันทึก และการจัดการของเสียยังทำได้ครบ จึงค่อยทบทวนรอบต่อไป

ตัวอย่างนี้ไม่ได้บอกว่าจำนวนดังกล่าวเหมาะกับฟาร์มใด และไม่ใช่การคำนวณกำไร จุดประสงค์คือแสดงลำดับคิด: ระบุคอขวด → ทดลอง → วัดผล → แก้ไข → ค่อยพิจารณาขยาย

## มือใหม่ควรรู้

การเริ่มน้อยเกินไปอาจทำให้ต้นทุนต่อหน่วยสูง แต่การเริ่มมากเกินความสามารถอาจทำให้สุขภาพ ของเสีย และเงินสดเสียหายพร้อมกัน ไม่มีสูตรที่ตัดสินได้จากจำนวนสุกรอย่างเดียว

## ลงมือทำหน้าคอก

ทำตาราง capacity โดยให้เขียนหลักฐานของแต่ละด้าน ไม่ใช่เพียงคำว่า “พอ” ระบุจำนวนคน ชั่วโมงทำงาน แหล่งน้ำ ความจุเก็บอาหาร ระบบไฟฟ้าสำรอง พื้นที่แยกสัตว์ป่วย ช่องทางสัตวแพทย์ และแผนของเสีย จากนั้นให้คนที่ไม่ได้เป็นผู้ตัดสินใจหลักช่วยตรวจจุดบอด

กำหนด gate ที่ต้องผ่านก่อนขยาย เช่น บันทึกอาหารและน้ำครบ ระบบเข้าออกทำได้จริง ของเสียไม่ล้น ไม่มีงานค้างที่กระทบสวัสดิภาพ และมีผู้ซื้อ/แผนขายที่ยืนยันได้ หาก gate ใดไม่ผ่าน ให้แก้ระบบก่อนเพิ่มจำนวน

## จุดที่มักเข้าใจผิด

**เริ่มมากแล้วจะคืนทุนเร็วกว่าเสมอ.** รายรับอาจเพิ่ม แต่ความเสี่ยงและเงินสดที่ต้องใช้ก็เพิ่มเช่นกัน

**โรงเรือนว่างแปลว่ายังรับหมูได้.** ต้องตรวจน้ำ ไฟฟ้า คน สุขภาพ ของเสีย และตลาดด้วย

**ฟาร์มเล็กไม่ต้องทำ biosecurity.** ขนาดไม่ใช่เหตุผลให้ละเลยการควบคุมคน รถ สุกรใหม่ และอุปกรณ์

**ใช้จำนวนจากฟาร์มข้างเคียงได้.** ความจุและคอขวดของแต่ละฟาร์มต่างกัน

**ถ้ารอบแรกมีปัญหาให้เพิ่มจำนวนเพื่อเฉลี่ยต้นทุน.** ควรแก้สาเหตุก่อน เพราะการขยายอาจขยายความเสียหายด้วย

## เชื่อมต่อไปหัวข้อถัดไป

เมื่อกำหนดจำนวนโดยดู capacity แล้ว ขั้นต่อไปคือกำหนดว่า “ฟาร์มต้องการบรรลุอะไร” ทั้งเป้าหมายการผลิต คุณภาพ ตลาด ความเสี่ยง และข้อจำกัดของเจ้าของในหัวข้อ 3.3

## สรุปท้ายหัวข้อ

จำนวนเริ่มต้นที่ดีไม่ใช่จำนวนที่มากที่สุดหรือเล็กที่สุด แต่คือจำนวนที่ระบบของเจ้าของดูแลได้จริงภายใต้ทุน แรงงาน ที่ดิน น้ำ อาหาร ตลาด biosecurity ของเสีย และความสามารถจัดการ การเริ่มแบบเป็นระยะและใช้ gate จากหลักฐานช่วยลดการขยายความเสี่ยง โดยต้องรักษามาตรฐานสุขภาพ สวัสดิภาพ และสิ่งแวดล้อมตั้งแต่วันแรก
