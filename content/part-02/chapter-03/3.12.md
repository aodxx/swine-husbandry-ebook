# 3.12 Checklist ก่อนเริ่มเลี้ยง

> **สรุปสั้น:** Checklist นี้เป็นเครื่องมือช่วยตรวจความพร้อมก่อนรับสุกร ไม่ใช่ใบอนุญาต ใบรับรองสุขภาพ หรือคำรับรองความคุ้มทุน แต่ละข้อควรมีหลักฐาน ผู้รับผิดชอบ และวันที่ตรวจ หาก gate สำคัญยังไม่ผ่าน ควรหยุดรับสุกรและแก้ระบบก่อน

## ใช้ checklist เพื่อหยุดความผิดพลาด ไม่ใช่เพื่อเร่งเริ่ม

หลังอ่านหัวข้อ 3.1–3.11 เจ้าของควรตอบได้ว่าฟาร์มจะเลี้ยงอะไร จำนวนเท่าใด ใช้ระบบใด ใช้เงินก้อนแรกและเงินหมุนเวียนเท่าไร ขายให้ใคร และจะดูแลสุขภาพ สวัสดิภาพ สิ่งแวดล้อม และข้อมูลอย่างไร Checklist ช่วยเปลี่ยนคำตอบเหล่านี้เป็น gate ที่ตรวจได้

การติ๊กครบโดยไม่มีเอกสารหรือไม่มีคนทำงานจริงไม่ใช่ความพร้อม มกษ. 6403-2565 ครอบคลุมองค์ประกอบสำคัญของฟาร์มสุกรตั้งแต่สถานที่ โรงเรือน การจัดการ อาหาร น้ำ บุคลากร สุขภาพ สวัสดิภาพ สิ่งแวดล้อม และบันทึก [1] [2] กรมปศุสัตว์มีหลักเกณฑ์ตรวจประเมินและแบบฟอร์ม GAP ที่ต้องตรวจ version ก่อนใช้ [3] [4]

## สถานะของแต่ละข้อ

ให้ใช้สถานะที่บอกการตัดสินใจ ไม่ใช่เพียง “ใช่/ไม่ใช่”

| สถานะ | ความหมาย |
|---|---|
| ผ่าน | มีหลักฐาน ตรวจซ้ำได้ และผู้รับผิดชอบทำได้จริง |
| ไม่ผ่าน | มีความเสี่ยงหรือขาดข้อกำหนด ต้องแก้ก่อนเริ่ม |
| ยังไม่ทราบ | ยังไม่มีข้อมูล ห้ามตีความว่า “ผ่าน” |
| ต้องปรึกษา | ต้องให้สัตวแพทย์ ผู้ทำบัญชี วิศวกร ทนาย หรือหน่วยงานที่มีอำนาจช่วยยืนยัน |
| ไม่เกี่ยวข้อง | ใช้ได้เฉพาะเมื่อบันทึกเหตุผลว่าทำไมจึงไม่เกี่ยวข้อง |

## Gate 1: สิทธิ ที่ตั้ง และข้อกำหนดราชการ

| รายการตรวจ | หลักฐานที่ควรมี | สถานะ |
|---|---|---|
| สิทธิใช้ที่ดิน/พื้นที่ | โฉนด สัญญาเช่า หรือเอกสารสิทธิที่ตรวจแล้ว | ____ |
| ทางเข้าและการขนส่ง | ตรวจเส้นทาง รถ และการเข้าออกจริง | ____ |
| ผังฟาร์ม | แบบแสดงโรงเรือน โซนสะอาด/เสี่ยง และ flow | ____ |
| มาตรฐานฟาร์ม | ตรวจ มกษ. ฉบับล่าสุดและหลักเกณฑ์ที่เกี่ยวข้อง | ____ |
| ใบอนุญาต/การขึ้นทะเบียน | รายการหน่วยงานและผลยืนยันตามที่ตั้ง | ____ |
| สิ่งแวดล้อม | แผนมูล น้ำเสีย กลิ่น ซาก และการตรวจหน่วยงาน | ____ |
| การก่อสร้าง | ตรวจข้อกำหนดท้องถิ่นก่อนเซ็นสัญญา | ____ |

**Legal/dynamic note:** มกษ. 6403-2565 และแบบฟอร์ม/หลักเกณฑ์กรมปศุสัตว์อาจมีการปรับปรุง ต้องบันทึก version และ last reviewed. Checklist ไม่แทนการยื่นขออนุญาตและไม่ยืนยันว่ากิจการของเจ้าของไม่ต้องขออนุญาตใด ๆ

## Gate 2: เป้าหมาย ระบบ และจำนวน

| รายการตรวจ | คำถามหลัก | สถานะ |
|---|---|---|
| เป้าหมาย | จะผลิตอะไรและขายให้ใคร | ____ |
| ระบบ | พ่อแม่พันธุ์ หมูขุน Farrow-to-finish หรือ Wean-to-finish | ____ |
| จำนวน | จำนวนสัมพันธ์กับทุน คน น้ำ อาหาร ตลาด biosecurity และของเสียหรือไม่ | ____ |
| Flow | สุกร คน อาหาร รถ และของเสียเดินอย่างไร | ____ |
| คอขวด | อะไรจำกัดระบบก่อน เช่น น้ำ คน พื้นที่ หรือการขาย | ____ |
| แผนขยาย | มี gate จากข้อมูลจริงก่อนเพิ่มจำนวนหรือไม่ | ____ |

ไม่มีจำนวนสุกรหรือระบบใดดีที่สุดทุกฟาร์ม การตัดสินใจต้องเชื่อมกับทรัพยากรและความสามารถจัดการ ไม่ใช่ลอกฟาร์มอื่น

## Gate 3: โรงเรือน น้ำ ไฟ และอุปกรณ์

| รายการตรวจ | หลักฐานที่ควรมี | สถานะ |
|---|---|---|
| โรงเรือน | แบบและสเปกเหมาะกับช่วงวัย/ระบบ | ____ |
| พื้นที่แยก | พื้นที่สุกรใหม่ ป่วย คัดออก และเก็บวัสดุ | ____ |
| น้ำ | แหล่งน้ำ ผลตรวจ/แผนสำรอง และระบบจ่าย | ____ |
| ไฟฟ้า | โหลดไฟ ระบบสำรอง และผู้ซ่อม | ____ |
| อาหาร | แหล่งซื้อ การเก็บ และการป้องกันความชื้น/พาหะ | ____ |
| อุปกรณ์ | ราง จุดน้ำ พัดลม เครื่องมือ และอุปกรณ์แยกโซน | ____ |
| ซ่อมบำรุง | อะไหล่ ช่าง และตารางตรวจ | ____ |

**Recommendation:** ทดสอบระบบเปล่าก่อนรับสุกรจริง ให้คนทำงานเดินตาม flow และจำลองไฟดับ น้ำขัดข้อง อาหารล่าช้า และสุกรป่วย

## Gate 4: สุกร แหล่งที่มา และสุขภาพ

| รายการตรวจ | หลักฐานที่ควรมี | สถานะ |
|---|---|---|
| แหล่งสุกร | ผู้ขาย/ฟาร์มต้นทางและข้อมูลที่ตรวจสอบได้ | ____ |
| สุขภาพก่อนรับ | health information และผู้ประเมิน | ____ |
| การรับเข้า | จุดรับ รถ คน และการแยกความเสี่ยง | ____ |
| โปรแกรมสุขภาพ | แผนจากสัตวแพทย์ผู้ควบคุมฟาร์ม | ____ |
| สัตว์ป่วย/ซาก | วิธีแยก ดูแล และจัดการตามผู้เชี่ยวชาญ/ข้อกำหนด | ____ |
| บันทึก | หมายเลข รุ่น การย้าย อาหาร สุขภาพ และการขาย | ____ |
| Biosecurity | SOP คน รถ อุปกรณ์ อาหาร น้ำ และสัตว์พาหะ | ____ |

> **HIGH_RISK_CONTENT:** ส่วนนี้เป็น gate การเตรียมระบบ ไม่ใช่การวินิจฉัยหรือรักษาโรค ไม่กำหนดยา วัคซีน หรือระยะกักกัน ให้สัตวแพทย์ผู้ควบคุมฟาร์มออกแบบและทบทวนโปรแกรมสุขภาพ

## Gate 5: คนและงานประจำ

| รายการตรวจ | หลักฐานที่ควรมี | สถานะ |
|---|---|---|
| ผู้รับผิดชอบ | ชื่อ หน้าที่ และผู้แทนเมื่อไม่อยู่ | ____ |
| SOP | คู่มือให้อาหาร น้ำ ล้างคอก สุขภาพ และฉุกเฉิน | ____ |
| ทักษะ | บันทึกการฝึกและการประเมินทำงานจริง | ____ |
| ตารางงาน | งานประจำและงานตามรอบไม่ชนกันเกินกำลัง | ____ |
| ความปลอดภัย | PPE การเคลื่อนย้าย และพื้นที่ทำงานปลอดภัย | ____ |
| การสื่อสาร | ช่องทางแจ้งเหตุผิดปกติและเรียกผู้เชี่ยวชาญ | ____ |

ถ้างานสำคัญขึ้นกับคนคนเดียวโดยไม่มีคนแทน นั่นคือความเสี่ยงของระบบ ไม่ใช่หลักฐานว่าคนหลักเก่งพอ

## Gate 6: เงินลงทุนและเงินทุนหมุนเวียน

| รายการตรวจ | หลักฐานที่ควรมี | สถานะ |
|---|---|---|
| Capex register | แบบ รายการ สเปก ใบเสนอราคา วันที่ และค่าติดตั้ง | ____ |
| เงินสดเริ่มต้น | เงินที่จ่ายก่อนรับสุกรและก่อนรายรับ | ____ |
| Cash-flow | ตารางเงินออก/เข้าและวันรับเงินจริง | ____ |
| Downside case | กรณีขายช้า ต้นทุนเพิ่ม หรือราคาลด | ____ |
| แหล่งเงิน | สัญญา ดอกเบี้ย ค่าธรรมเนียม และวันเบิก | ____ |
| เงินสำรอง | วิธีใช้และ trigger ไม่ใช่เงินกำไร | ____ |

ราคาสุกรและสินค้าเกษตรเป็นข้อมูล dynamic กรมปศุสัตว์และ สศก. เผยแพร่ข้อมูลตามช่วงเวลา [5] [6] อย่าใช้ตัวเลขราคาประกาศเป็นราคาตลอดรอบ และอย่าสร้างราคาก่อสร้าง/อาหารขึ้นเอง

## Gate 7: ตลาดก่อนซื้อ

| รายการตรวจ | หลักฐานที่ควรมี | สถานะ |
|---|---|---|
| ผู้ซื้อ | ชื่อผู้ติดต่อและประวัติ/ช่องทางตรวจสอบ | ____ |
| Specification | ประเภท คุณภาพ น้ำหนัก และเอกสาร | ____ |
| ปริมาณ/วันรับ | ข้อตกลงหรือการยืนยันที่เก็บได้ | ____ |
| วิธีชั่ง/หัก | เงื่อนไขราคาและการหักที่เข้าใจตรงกัน | ____ |
| ขนส่ง | ผู้รับผิดชอบ รถ ค่าใช้จ่าย และเส้นทาง | ____ |
| วันชำระ | วันรับเงินจริงและเงื่อนไขเครดิต | ____ |
| แผนสำรอง | เมื่อผู้ซื้อเลื่อน รับไม่ครบ หรือราคาผันผวน | ____ |

ราคาตลาดคือสัญญาณ ไม่ใช่สัญญาซื้อขาย การมีผู้ซื้อที่พูดคุยกันแล้วไม่เท่ากับมี buyer specification ที่ยืนยันได้

## Gate 8: เอกสารและการตัดสินใจ

ก่อนรับสุกร ให้รวบรวมแฟ้มอย่างน้อย: แบบผังและโรงเรือน เอกสารสิทธิ/การตรวจหน่วยงาน ใบเสนอราคา capex cash-flow แผนสุขภาพจากสัตวแพทย์ SOP รายชื่อคน แผน biosecurity แผนของเสีย buyer sheet และทะเบียนบันทึก

จากนั้นจัดประชุม go/no-go โดยให้คนที่ไม่ได้เป็นผู้ตัดสินใจหลักช่วยตรวจจุดบอด หากข้อใดมีสถานะ “ไม่ผ่าน” หรือ “ยังไม่ทราบ” และมีผลต่อกฎหมาย สุขภาพ สวัสดิภาพ ความปลอดภัยอาหาร เงินสด หรือสิ่งแวดล้อม ให้เลื่อนรับสุกรและแก้ไข/ขอคำยืนยันก่อน

## EXAMPLE_ONLY: สรุป Go / Hold

ตารางนี้เป็นตัวอย่างแบบฟอร์ม ไม่ใช่เกณฑ์อนุมัติ

| Gate | ผลตัวอย่าง | การตัดสินใจตัวอย่าง |
|---|---|---|
| ที่ตั้ง/สิทธิ | ผ่านบางส่วน | Hold จนหน่วยงานยืนยัน |
| โรงเรือน/น้ำไฟ | ผ่าน | ตรวจซ้ำก่อนรับ |
| สุขภาพ | ต้องปรึกษา | Hold จนสัตวแพทย์ทบทวน |
| เงินสด | ยังไม่ทราบ | ทำ cash-flow ใหม่ |
| ตลาด | มีผู้ติดต่อแต่ยังไม่ยืนยัน | ห้ามซื้อหมู |
| ของเสีย | ผ่านตามแบบเบื้องต้น | ตรวจข้อกำหนดจริง |
| คน/SOP | ผ่านบางส่วน | ฝึกและทดสอบงาน |

ผลลัพธ์ตัวอย่างคือ **HOLD** ไม่ใช่เพราะฟาร์มล้มเหลว แต่เพราะหลักฐานสำคัญยังไม่ครบ

## สิ่งที่ควรทบทวนเป็นพิเศษ

ข้อมูลต่อไปนี้เปลี่ยนตามเวลาและพื้นที่: มาตรฐาน/แบบฟอร์มรับรอง กฎหมายและใบอนุญาต ราคาสุกร ราคาอาหาร ค่าแรง ค่าขนส่ง ข้อกำหนดสิ่งแวดล้อม และเงื่อนไขผู้ซื้อ ให้บันทึกวันที่ตรวจทุกครั้ง และอย่าเขียน “ตรวจแล้ว” โดยไม่มีแหล่งหรือเอกสาร

กรมปศุสัตว์มีหลักเกณฑ์ตรวจประเมิน GAP และแบบฟอร์มฉบับปรับปรุงครั้งที่ 2-2568 [3] [4] แต่เอกสารดังกล่าวเป็นส่วนของกระบวนการมาตรฐาน ไม่ใช่การยืนยันว่าฟาร์มใดผ่านแล้ว และไม่แทนการตรวจข้อกำหนดท้องถิ่น

## มือใหม่ควรรู้

Checklist ที่ดีไม่ใช่กระดาษที่ติ๊กครบเร็วที่สุด แต่คือเครื่องมือที่ช่วยให้รู้ว่าข้อมูลใดยังขาดและใครต้องไปหาคำตอบ การเลื่อนเริ่มเพื่อแก้ gate สำคัญมักปลอดภัยกว่าการรับสุกรแล้วแก้ระบบไปพร้อมกับสัตว์ที่อยู่ในความดูแล

## ลงมือทำหน้าฟาร์ม

พิมพ์ checklist หนึ่งชุดต่อระบบ/สถานที่ ใช้สถานะและแนบหลักฐานทุกข้อ ให้เจ้าของ ผู้ปฏิบัติงาน สัตวแพทย์ ผู้ทำบัญชี และหน่วยงานที่เกี่ยวข้องตรวจเฉพาะส่วนของตน แล้วบันทึกวันประชุม go/no-go

หลังเริ่มแล้วให้ทบทวน checklist เมื่อเปลี่ยนจำนวน ระบบ แหล่งสุกร ตลาด โรงเรือน หรือข้อกำหนด ไม่ควรเก็บไว้ใช้เพียงครั้งเดียวก่อนซื้อ

## จุดที่มักเข้าใจผิด

**ติ๊กครบแล้วแปลว่าได้รับอนุญาต.** Checklist ไม่ใช่ใบอนุญาตหรือใบรับรอง

**ยังไม่ทราบให้ถือว่าผ่าน.** ข้อมูลสำคัญที่ยังไม่ทราบต้องเป็นงานค้างหรือ Hold

**มีเงินลงทุนก็เริ่มได้.** ต้องตรวจเงินหมุนเวียน สุขภาพ ตลาด คน และของเสีย

**ราคาเฉลี่ยคือราคาของฟาร์ม.** ต้องดูวันที่ พื้นที่ คุณภาพ ปริมาณ และเงื่อนไขจริง

**ให้สัตวแพทย์ตรวจทีหลัง.** โปรแกรมสุขภาพควรวางก่อนรับสุกร และการรักษาต้องอยู่ภายใต้ผู้มีคุณสมบัติ

**ฟาร์มเล็กตัด gate ได้.** ขนาดเปลี่ยนวิธีจัดการ แต่ไม่ลบความรับผิดชอบด้านสัตว์ คน อาหาร และสิ่งแวดล้อม

## สรุปท้ายบท

ก่อนเริ่มเลี้ยงต้องตรวจสิทธิและข้อกำหนด ที่ตั้งและระบบ เป้าหมายและจำนวน สุกรและสุขภาพ คนและ SOP เงินลงทุนและเงินหมุนเวียน ตลาด และของเสีย โดยทุกข้อสำคัญควรมีหลักฐาน ผู้รับผิดชอบ และวันที่ตรวจ กฎหมาย ราคา และแบบฟอร์มต้องทบทวนจากแหล่งไทยปัจจุบัน Checklist ช่วยตัดสินใจแต่ไม่แทนหน่วยงาน สัตวแพทย์ ผู้ทำบัญชี หรือการตรวจฟาร์มจริง หาก gate สำคัญยังไม่ผ่าน ให้ Hold ก่อนรับสุกร
