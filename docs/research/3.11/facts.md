# Fact List — 3.11 วางแผนตลาดก่อนซื้อหมู

วันที่สกัด: 2026-08-23

## FACT
1. ราคาสุกรที่เกษตรกรขายได้และราคาตลาดเป็นข้อมูลตามช่วงเวลา/พื้นที่ ไม่ใช่ราคาที่รับประกันสำหรับฟาร์มหนึ่ง [S311-01] [S311-02]
2. เงื่อนไขการขายที่ต้องยืนยันมีผู้ซื้อ ปริมาณ คุณภาพ/น้ำหนัก วันรับ ขนส่ง เอกสาร วิธีชั่ง การหัก และวันชำระเงิน [S311-03] [S311-04]
3. มกษ. 6403-2565 ให้ความสำคัญกับการบันทึกข้อมูลและการผลิตที่ตรวจสอบย้อนกลับได้ [S311-05]
4. การซื้อสุกรก่อนยืนยันตลาดทำให้ฟาร์มรับความเสี่ยงด้านราคา เวลา พื้นที่ และเงินทุนหมุนเวียนเองทั้งหมด [S311-01] [S311-02]

## INTERPRETATION
“มีตลาด” ควรหมายถึงมี buyer specification และเงื่อนไขการรับซื้อที่เข้าใจตรงกัน ไม่ใช่เพียงรู้ว่ามีคนรับซื้อสุกรในพื้นที่.

## PRACTICAL IMPLICATION
ทำ buyer sheet และบันทึกคำยืนยันเป็นลายลักษณ์อักษร ตรวจเงื่อนไขซ้ำก่อนรับสุกร และมีแผนสำรองหากผู้ซื้อเลื่อน/รับไม่ครบ.

## UNCERTAINTY
ราคาจริงขึ้นกับตลาด วันขาย คุณภาพ ปริมาณ การขนส่ง และการหักตามสัญญา จึงไม่ควรคาดการณ์รายรับจากราคาประกาศเพียงค่าเดียว.
