# Conflict & Uncertainty Check — 1.10 จากพ่อแม่พันธุ์ถึงสุกรตลาด

วันที่ตรวจ: 2026-08-23

| ประเด็น | Source ที่ต่างกัน | การวิเคราะห์ | การตัดสินใจใน Draft |
|---|---|---|---|
| จุดแบ่งระยะ nursery/finishing | USDA แยก nursery กับ finishing; UC Davis อธิบาย nursery และ grow-finish ตามบริบทสหรัฐฯ | เป็นความต่างของโครงสร้างระบบ ไม่ใช่ข้อขัดแย้งทางชีววิทยา | ใช้คำว่า “ระยะหลังหย่านม/อนุบาล” และ “เติบโต/ขุน” พร้อมบอกว่าฟาร์มอาจรวมระยะ |
| ระบบรวมฟาร์มกับระบบแยกหน่วย | USDA อธิบาย farrow-to-finish, farrow-to-wean, nursery และ finishing เป็นกิจการเฉพาะ | เป็น business/production organization ที่ต่างกันตามโครงสร้างอุตสาหกรรม | นำเสนอเป็นทางเลือกของ production flow ไม่จัดอันดับว่าแบบใดเหมาะกับไทยทุกฟาร์ม |
| ตัวเลขอายุ น้ำหนัก และระยะเวลา | USDA/UC Davis ให้ตัวเลขของสหรัฐฯ; Pork Gateway ให้ตัวอย่างการจัดตารางและ performance ในระบบหนึ่ง | ตัวเลขขึ้นกับพันธุ์ ระบบ อากาศ สุขภาพ ตลาด และปี | ไม่ใช้ตัวเลขเป็นเป้าหมายในหัวข้อนี้; หากกล่าวถึงต้องติดป้ายสหรัฐฯ และไม่ generalize |
| นิยาม AIAO | Pork Gateway เน้นกลุ่มใกล้เคียงและพื้นที่ว่างระหว่างกลุ่ม; UMN เน้นกลุ่มคลอด/หย่านมและการทำความสะอาด | เป็นรายละเอียดระดับ implementation ที่ต่างกัน ไม่ขัดกัน | อธิบายหลักการร่วมและไม่สร้าง protocol บังคับ |
| welfare threshold | WOAH ระบุว่าต้องปรับ threshold ตามภูมิภาค สุขภาพฝูง พันธุ์/ลูกผสม ภูมิอากาศ และระบบ | ไม่สามารถยกค่ามาตรฐานเดียวมาใช้กับฟาร์มไทย | หลีกเลี่ยง numeric welfare target และเชื่อมไปหัวข้อเฉพาะ |
| แหล่ง Tier A ไทย | ค้นเพิ่มแล้วไม่พบเอกสารไทยที่อธิบาย taxonomy ครบและตรวจข้อความได้โดยตรง | ไม่ใช่หลักฐานว่าไม่มีเอกสารไทยทั้งหมด แต่เป็นข้อจำกัดการเข้าถึง/การค้นครั้งนี้ | บันทึก `NOT FOUND` และใช้ WOAH/USDA/academic extension เป็นแหล่งหลัก พร้อมระบุบริบท |
| health/biosecurity claims | แหล่ง AIAO/UMN กล่าวถึงโรคและการลดความเสี่ยง | เนื้อหานี้ไม่ใช่หัวข้อวินิจฉัยหรือรักษา และไม่ได้พิสูจน์ผลกับทุกระบบ | กล่าวเฉพาะหลักการ flow/การแยกกลุ่ม; ไม่ใส่คำแนะนำยา วัคซีน หรือการรักษา |

## Unresolved issues

ไม่มี conflict สำคัญที่ขัดขวางการเขียนภาพรวม หาก Draft ไม่ใส่ตัวเลขเป้าหมาย ไม่อ้างระบบสหรัฐฯ เป็นมาตรฐานไทย และแยก Fact ออกจาก Interpretation อย่างชัดเจน
