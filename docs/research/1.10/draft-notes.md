# Draft Notes — 1.10 จากพ่อแม่พันธุ์ถึงสุกรตลาด

วันที่ร่าง: 2026-08-23
สถานะ: DRAFTED

## Editorial decisions

ร่างอธิบายสายการผลิตโดยไม่กำหนดตัวเลขเป้าหมาย ใช้ตารางเพื่อแยกบทบาทและจุดส่งต่อ ใช้ AIAO เป็นหลักการจัด flow ไม่ใช่ protocol บังคับ และระบุชัดว่าตัวอย่างโครงสร้างของสหรัฐฯ ไม่ใช่มาตรฐานไทย

## Claim map for fact check

- คำจำกัดความ commercial pig production และ *Sus scrofa*: ตรวจกับ WOAH โดยตรง
- ประเภท farrow-to-finish, farrow-to-wean, nursery, finishing และนิยาม gilt/sow: ตรวจกับ USDA ERS โดยตรง
- ลำดับ flow และ AIAO: ตรวจกับ Pork Information Gateway และ UMN Extension
- ประโยชน์ของการเชื่อมข้อมูล breeding-to-market: ตรวจกับงานวิจัย Frontiers และไม่ขยายผลเกินระบบศึกษา
- ข้อความเรื่อง welfare threshold ตามบริบท: ตรวจกับ WOAH
- การประยุกต์สำหรับฟาร์มไทยและรายการบันทึก: ระบุเป็น practical interpretation ไม่กล่าวว่าเป็นข้อกำหนดจาก Source

## Out-of-scope check

ไม่ใส่รายละเอียดสูตรอาหาร ยา วัคซีน การรักษา การวินิจฉัย ตัวเลข performance หรือประวัตินิพนธ์ฟาร์ม จึงไม่เปิด High-Risk Content ในหัวข้อนี้
