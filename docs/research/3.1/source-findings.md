# External Source Findings — 3.1 ประเมินความพร้อมก่อนเลี้ยง

วันที่เข้าถึง: 2026-08-23

## Thai Tier A findings

1. มกอช. ระบุ มกษ. 6403-2565: https://e-book.acfs.go.th/Book_view/312 — ชื่อมาตรฐาน “การปฏิบัติทางการเกษตรที่ดีสำหรับฟาร์มสุกร” ฉบับ 2565 และเผยแพร่โดยสำนักงานมาตรฐานสินค้าเกษตรและอาหารแห่งชาติ.

2. มกอช. สรุปขอบข่ายและสาระสำคัญ: https://agristandards.acfs.go.th/%E0%B8%9F%E0%B8%B2%E0%B8%A3%E0%B9%8C%E0%B8%A1%E0%B8%AA%E0%B8%B8%E0%B8%81%E0%B8%A3/ — ครอบคลุมฟาร์มสุกรพ่อแม่พันธุ์ สุกรอนุบาล หรือสุกรขุน อย่างใดอย่างหนึ่งหรือหลายอย่าง; องค์ประกอบฟาร์ม การจัดการ บุคลากร สุขภาพ สวัสดิภาพ สิ่งแวดล้อม และการบันทึกข้อมูล.

3. สาระจากหน้า มกอช. เรื่ององค์ประกอบฟาร์ม: สถานที่ตั้งควรมีหลักฐานการยินยอมจากราชการส่วนท้องถิ่น มีความเสี่ยงการปนเปื้อนเหมาะสม การคมนาคมเข้าถึงได้ ไม่อยู่ในบริเวณน้ำท่วมขัง และมีแหล่งน้ำสะอาดเพียงพอ; ผังควบคุมคน/สัตว์และโรงเรือนต้องแข็งแรง ถูกสุขลักษณะ ระบายอากาศดี และเหมาะกับสายพันธุ์ ขนาด และอายุ.

4. สาระจากหน้า มกอช. เรื่องการจัดการ: ต้องมีคู่มือและ SOP ที่ครอบคลุมการเตรียมโรงเรือน อาหาร/น้ำ สุขภาพ สัตว์พาหะ สุขาภิบาล สิ่งแวดล้อม สวัสดิภาพ และบันทึกข้อมูล; บุคลากรต้องเพียงพอและมีสัตวแพทย์ผู้ควบคุมฟาร์มตามข้อกำหนดที่เกี่ยวข้อง.

5. หน้า กรมปศุสัตว์เรื่องฟาร์มเลี้ยงสัตว์: https://certify.dld.go.th/index.php/th/thdsxb-menu/reuxng-den-thi-na-snci/farm-leiyng-satw/farm — เป็นหน่วยงาน/ช่องทางข้อมูลด้านการตรวจสอบและรับรองสินค้าปศุสัตว์; หน้าเว็บระบุสงวนลิขสิทธิ์ พ.ศ. 2568.

6. หน้าแบบฟอร์ม GAP ของกรมปศุสัตว์: https://certify.dld.go.th/index.php/th/thdsxb-menu/reuxng-den-thi-na-snci/farm-leiyng-satw/fm-gap — แสดงแบบฟอร์ม FM-GAP-FAM-01 สำหรับฟาร์มเลี้ยงสัตว์.

## Legal/dynamic caution

ห้ามสรุปจากหน้าเว็บสรุปว่าใบรับรอง GAP เป็นใบอนุญาตประกอบกิจการทุกกรณี; ต้องตรวจราชการส่วนท้องถิ่น กฎหมายสิ่งแวดล้อม และประกาศ/ข้อบัญญัติที่ใช้กับพื้นที่จริงก่อนลงทุน. ห้ามใช้ระยะห่างหรือค่าความจุจากต่างประเทศเป็นข้อกำหนดไทย.

## Content boundary

หัวข้อ 3.1 จะให้กรอบประเมินความพร้อมเชิงระบบ ไม่ตัดสินว่าโครงการใดควรลงทุน และไม่สร้างต้นทุนปัจจุบัน. ตัวอย่างการคำนวณใด ๆ ต้องติดป้าย EXAMPLE_ONLY.
