# Fact List — 3.2 ควรเริ่มกี่ตัว

วันที่สกัด: 2026-08-23

## FACT

1. มกษ. 6403-2565 ครอบคลุมองค์ประกอบฟาร์ม การจัดการ บุคลากร สุขภาพ สวัสดิภาพ สิ่งแวดล้อม และการบันทึกข้อมูล ซึ่งทุกด้านเป็นข้อจำกัดของจำนวนสุกรที่ระบบรองรับ [S302-01]
2. Biosecurity มีทั้งการป้องกันความเสี่ยงจากภายนอกและการควบคุมการแพร่ภายในฟาร์ม การมีสุกรมากขึ้นไม่ได้ทำให้ระบบ biosecurity ดีขึ้นโดยอัตโนมัติ [S302-02] [S302-03]
3. จำนวนเริ่มต้นต้องสัมพันธ์กับความสามารถจัดการน้ำ อาหาร แรงงาน สุขภาพ สวัสดิภาพ ของเสีย และตลาด ไม่ใช่สัมพันธ์กับพื้นที่คอกอย่างเดียว [S302-01]
4. การเริ่มแบบเป็นระยะหรือ pilot สามารถใช้ทดสอบขั้นตอนและข้อมูลจริงก่อนขยาย แต่ต้องไม่ขัดข้อกำหนดหรือทำให้สัตว์ได้รับการดูแลไม่เพียงพอ [S302-01] [S302-02]

## INTERPRETATION

จำนวนที่เหมาะสมคือจำนวนที่ระบบสามารถดูแล ตรวจพบความผิดปกติ จัดการของเสีย และขายผลผลิตได้อย่างสม่ำเสมอภายใต้เงินสดและแรงงานจริงของเจ้าของ ไม่ใช่จำนวนสูงสุดที่ยัดลงคอกได้.

## PRACTICAL IMPLICATION

ให้กำหนด capacity จากคอขวดที่เล็กที่สุด เช่น น้ำสำรอง แรงงานช่วงให้อาหาร ระบบระบายอากาศ พื้นที่แยกสัตว์ป่วย หรือระบบของเสีย แล้วเริ่มต่ำกว่าความจุที่ยังไม่ผ่านการทดสอบ. ทบทวนหลังจบรอบการเลี้ยงก่อนเพิ่มจำนวน.

## UNCERTAINTY

ไม่มีจำนวนสุกรหรืออัตราแรงงานเดียวที่ใช้ได้กับทุกระบบไทย เพราะชนิดสุกร โรงเรือน ระบบอัตโนมัติ ฤดู ตลาด และทักษะผู้เลี้ยงต่างกัน.
