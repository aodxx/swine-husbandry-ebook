# Fact List — 3.12 Checklist ก่อนเริ่มเลี้ยง

วันที่สกัด: 2026-08-23

## FACT
1. มกษ. 6403-2565 ครอบคลุมสถานที่ ผัง โรงเรือน การจัดการ อาหาร น้ำ บุคลากร สุขภาพ สวัสดิภาพ สิ่งแวดล้อม และบันทึก ซึ่งเป็นรายการสำคัญก่อนเริ่มฟาร์ม [S312-01] [S312-02]
2. กรมปศุสัตว์เผยแพร่หลักเกณฑ์ตรวจประเมิน GAP และแบบฟอร์มฉบับปรับปรุง จึงต้องตรวจ version ล่าสุดก่อนใช้ [S312-03] [S312-04]
3. ราคาและข้อกำหนดบางเรื่องเปลี่ยนตามเวลา/พื้นที่ checklist ต้องมีช่องวันที่ตรวจ แหล่งอ้างอิง ผู้รับผิดชอบ และหลักฐาน [S312-05]
4. Checklist ช่วยตรวจความพร้อมแต่ไม่ใช่ใบอนุญาต ใบรับรองสุขภาพ คำแนะนำทางการเงิน หรือการอนุมัติลงทุน [S312-03] [S312-04]

## INTERPRETATION
คำตอบ “พร้อม/ไม่พร้อม” ควรเกิดจากหลักฐานและ gate ที่กำหนด ไม่ใช่การติ๊กครบโดยไม่มีเอกสารหรือผู้รับผิดชอบ.

## PRACTICAL IMPLICATION
แบ่ง checklist เป็น gate: สิทธิ/กฎหมาย, สถานที่/ระบบ, สุกร/สุขภาพ, คน/งาน, เงินสด/ตลาด, ของเสีย/ชุมชน และเอกสาร. ช่องสำคัญที่ยังไม่ผ่านให้หยุดรับสุกรหรือส่งต่อผู้เชี่ยวชาญ.

## UNCERTAINTY
ข้อกำหนดใบอนุญาต สิ่งแวดล้อม และรายละเอียดฟาร์มขึ้นกับที่ตั้ง/กิจการ ต้องตรวจหน่วยงานที่มีอำนาจก่อนเริ่มจริง.
