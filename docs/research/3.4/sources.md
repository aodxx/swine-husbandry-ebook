# Sources — 3.4 เลือกระบบพ่อแม่พันธุ์หรือหมูขุน

วันที่ประเมิน: 2026-08-23

| Source | Tier | การใช้ |
|---|---|---|
| มกอช. มกษ. 6403-2565 และหน้าอธิบายฟาร์มสุกร | A | ขอบข่ายฟาร์มพ่อแม่พันธุ์/อนุบาล/ขุน และข้อกำหนดร่วม |
| กรมปศุสัตว์ — สุกรขุน/ฟาร์มเลี้ยงสัตว์ | A | บริบทการผลิตและช่องทางมาตรฐานไทย |
| Penn State Extension — Swine Production | D | ความแตกต่างของ farrow-to-feeder และ feeder/finishing systems |
| Alabama Cooperative Extension — Managing Feeder Pigs | D | หลักการว่าระบบขุนมีความซับซ้อนและแรงงานต่างจากระบบพ่อแม่พันธุ์; ไม่ใช้แทนมาตรฐานไทย |
