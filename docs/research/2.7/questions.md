# Research Questions — 2.7 จุดเด่น–จุดจำกัดของแต่ละพันธุ์

วันที่กำหนดขอบเขต: 2026-08-23

## Scope

หัวข้อนี้สังเคราะห์จุดเด่นและข้อจำกัดของพันธุ์/กลุ่มพันธุ์ที่กล่าวถึงใน 2.2–2.6 ได้แก่ Large White/Yorkshire, Landrace, Duroc, Pietrain และตัวอย่าง Hampshire, Berkshire, Tamworth, Meishan และสุกรพื้นเมืองไทย โดยเปรียบเทียบเป็นมิติ ไม่จัดอันดับ และไม่สรุปว่าพันธุ์ใดดีที่สุดโดยทั่วไป

การเปรียบเทียบจะใช้แกน phenotype, reproductive role, carcass/meat objective, robustness/adaptation, genetic diversity, data quality และ context dependence โดยแยกคำบรรยายพันธุ์ออกจาก performance ที่ต้องวัดจริง

ไม่ลงรายละเอียดประวัติรายพันธุ์ซ้ำกับ 2.2–2.6 ไม่กำหนดสายแม่/สายพ่อในเชิงระบบซึ่งอยู่ใน 2.8 ไม่อธิบาย heterosis ใน 2.9 ไม่เลือกพันธุ์ให้ฟาร์มรายกรณีซึ่งอยู่ใน 2.10 และไม่ใช้ตัวเลขต่างประเทศเป็นเป้าหมายไทย

## Research Questions

1. จุดเด่นและข้อจำกัดของแต่ละพันธุ์ควรประเมินตามมิติใดบ้าง
2. ข้อมูลด้าน phenotype, reproductive traits, carcass traits และ robustness มีหลักฐานระดับใดสำหรับแต่ละพันธุ์
3. เหตุใดคำว่า “เด่น” หรือ “ด้อย” จึงเปลี่ยนไปตามระบบผลิต ตลาด และสภาพแวดล้อม
4. พันธุ์ใดมีหลักฐานจากงานวิจัยประชากรไทย และอะไรยังสรุปไม่ได้
5. จะหลีกเลี่ยงการใช้ breed stereotype หรือ marketing claim เป็นคำตัดสินได้อย่างไร
6. ตารางเปรียบเทียบควรแสดง uncertainty และ context อย่างไรให้เกษตรกรใช้ได้จริง
7. ข้อมูลใดควรวัดในฟาร์มก่อนตัดสินใจเลือกพันธุ์

## Claim controls

ห้ามจัดอันดับ ห้ามใช้คำว่า “ดีที่สุด” โดยไม่มีเงื่อนไข ห้ามเหมารวม line ทั้งหมดจาก breed description เดียว และห้ามยกตัวเลข performance จากประเทศอื่นเป็น benchmark ไทย
