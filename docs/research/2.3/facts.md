# Fact List — 2.3 Landrace

วันที่สกัด: 2026-08-23

## FACT

1. Oklahoma State University ระบุว่า Landrace หลายสายมีบรรพประวัติจาก Danish Landrace ซึ่งพัฒนาขึ้นในเดนมาร์ก และ American Landrace ได้รับการพัฒนาต่อจากวัสดุพันธุกรรมหลายแหล่ง [SRC-090](https://breeds.okstate.edu/swine/american-landrace-swine)
2. OSU ระบุว่าการพัฒนา Landrace ในเดนมาร์กเริ่มราวปลายคริสต์ศตวรรษที่ 19 และเกี่ยวข้องกับการผสมสุกร Large White จากอังกฤษกับสุกรพื้นเมือง [SRC-090](https://breeds.okstate.edu/swine/american-landrace-swine)
3. คำบรรยาย American Landrace ของ OSU ระบุลักษณะสีขาว ลำตัวยาว ใบหูใหญ่และตกแนบหน้า หัวค่อนข้างยาว และมีลักษณะเนื้อที่เห็นได้จากภายนอก [SRC-090](https://breeds.okstate.edu/swine/american-landrace-swine)
4. OSU ระบุว่าสุกรแม่พันธุ์ Landrace ในคำบรรยายของสายอเมริกันถูกกล่าวถึงด้านความสามารถในการเลี้ยงลูกและการผลิตน้ำนม แต่ข้อความดังกล่าวเป็น breed description ของสายหนึ่ง ไม่ใช่ผลสรุปสำหรับ Landrace ทุก population [SRC-090](https://breeds.okstate.edu/swine/american-landrace-swine)
5. FAO แสดงว่าการจำแนก breed type และบทบาท maternal/paternal เชื่อมโยงกับวัตถุประสงค์ตลาดและตำแหน่งของพันธุ์ใน breeding system ไม่ใช่ลักษณะตายตัวที่ใช้กับทุกประเทศ [SRC-091](https://www.fao.org/4/ah759e/AH759E10.htm)
6. FAO อธิบายว่าพันธุ์และประชากรอาจถูกปรับปรุงผ่านการคัดเลือกและการผสมกับพันธุ์อื่นเพื่อเพิ่มการปรับตัวหรือสมรรถนะในสภาพท้องถิ่น และการประเมินต้องคำนึงถึงภูมิอากาศและระบบการเลี้ยง [SRC-091](https://www.fao.org/4/ah759e/AH759E10.htm)
7. กรมปศุสัตว์มีบทความเกี่ยวกับการสร้างสุกรพันธุ์แลนด์เรซสายพันธุ์ปากช่อง 1 และการศึกษาความแปรปรวนของลักษณะทางเศรษฐกิจในรุ่นที่ 4 และ 5 [SRC-092](https://e-wichakarn.dld.go.th/e-journal/?p=92)
8. การมีชื่อสาย เช่น Pak-Chong 1 หรือ American Landrace ไม่ได้ทำให้สรุปได้ทันทีว่า performance เท่ากัน เพราะ line, generation, selection objective และ environment อาจแตกต่างกัน [SRC-090](https://breeds.okstate.edu/swine/american-landrace-swine) [SRC-092](https://e-wichakarn.dld.go.th/e-journal/?p=92)
9. ลักษณะภายนอก เช่น สีขาว ลำตัวยาว หรือหูตก เป็นข้อมูลสังเกตเบื้องต้น ไม่ใช่หลักฐานเดียวสำหรับยืนยัน pedigree หรือ line [SRC-090](https://breeds.okstate.edu/swine/american-landrace-swine)
10. FAO แสดงว่าการรักษาความหลากหลายทางพันธุกรรมมีความสำคัญ เพราะประชากรท้องถิ่นอาจมีการปรับตัว คุณภาพเนื้อ หรือความทนต่อสภาพเครียดที่มีคุณค่า แม้ไม่ใช่สายที่ให้ productivity สูงสุดในระบบเข้มข้น [SRC-091](https://www.fao.org/4/ah759e/AH759E10.htm)

## INTERPRETATION

1. Landrace ควรอธิบายเป็นชื่อพันธุ์ที่มีหลายสายและหลายประวัติการพัฒนา ไม่ใช่ genotype เดียวทั่วโลก
2. คำบรรยายด้านแม่พันธุ์เป็นแนวโน้ม/บทบาทใน breeding system หรือสายที่อ้าง ไม่ใช่คำรับประกันจำนวนลูกหรือสมรรถนะของทุกตัว
3. ความยาวลำตัวหรือหูตกช่วยจำแนกเชิงภาพ แต่การตัดสินเพื่อทำพันธุ์ต้องใช้ข้อมูล pedigree และ performance records
4. การประเมิน Landrace ในไทยควรอ่านข้อมูล DLD เฉพาะสายร่วมกับ environment และระบบจัดการ ไม่โอนผลไปยัง Landrace ต่างสาย

## PRACTICAL IMPLICATION

1. เมื่อรับซื้อ Landrace ให้บันทึกประเทศ/แหล่งที่มา line, generation, pedigree และ breeding objective ไม่หยุดที่ชื่อพันธุ์
2. หากใช้เป็นแม่พันธุ์ ให้ประเมินข้อมูลจริงของ litter, mothering, สุขภาพ และอายุการใช้งานในระบบของฟาร์ม แยกจากคำบรรยายทั่วไป
3. ใช้สีและรูปทรงเป็นการคัดกรองเบื้องต้นเท่านั้น แล้วตรวจเอกสารพ่อแม่และรหัสประจำตัว
4. เปรียบเทียบ performance เฉพาะกลุ่มที่มี environment, nutrition, health และ management ใกล้กัน

## UNCERTAINTY

1. ข้อมูล DLD ที่เข้าถึงได้เป็น metadata/บทความหน้าเว็บและไม่ได้เปิดผลการทดลองเต็มในรอบนี้ จึงไม่ใช้ตัวเลขของปากช่อง 1 เป็น benchmark
2. แหล่ง OSU เป็นคำบรรยาย American Landrace และอ้างเอกสารประวัติรุ่นเก่า จึงไม่ใช้ยืนยัน performance ของสาย Landrace ในไทยปัจจุบัน
3. ยังไม่มี source ไทย Tier A ฉบับเดียวที่เปรียบเทียบ Landrace ทุกสายด้วยวิธีเดียวกันและ metadata ครบ
4. คำว่า “แม่ดี”, “น้ำนมดี”, “เนื้อดี” และ “ปรับตัวดี” ต้องกำหนด trait และวิธีวัดก่อนนำไปใช้ตัดสินใจ

## Numeric-claim decision

ไม่มีตัวเลข benchmark ในหัวข้อนี้ แม้เอกสาร FAO จะมีตารางผลการทดสอบในบริบทอื่น เพราะตัวเลขไม่ใช่ข้อมูล Landrace ไทยปัจจุบันและไม่ตรงกับเป้าหมายของหัวข้อ
