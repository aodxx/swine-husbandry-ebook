# Fact List — 2.1 สุกรพันธุ์แท้และลูกผสม

วันที่สกัด: 2026-08-23

## FACT

1. **Breed** คือกลุ่มสัตว์ที่ถูกจำแนกและรักษาลักษณะร่วมภายใต้กรอบการปรับปรุงพันธุ์หรือทะเบียนขององค์กร/โปรแกรมหนึ่ง ความหมายเชิงปฏิบัติไม่ควรถูกตัดสินจากสีหรือรูปร่างเพียงอย่างเดียว เพราะแหล่ง FAO แยกความแตกต่างระหว่างประชากรพื้นเมืองที่มี pedigree ไม่ชัดกับประชากรที่มี pedigree และการบันทึกหลายชั่วรุ่น [SRC-080](https://www.fao.org/4/ah806e/AH806E19.htm)
2. **Purebred** หมายถึงสัตว์ที่อยู่ในประชากร/สายการผสมที่มีบรรพประวัติและกฎการบันทึกตาม breeding program ที่กำหนด ไม่ได้แปลว่า “ดีกว่า” หรือมีพันธุกรรมเหมือนกันทุกตัว [SRC-079](https://www.canr.msu.edu/resources/swine_breeding_systems_for_alternative_pork_chains_breeding_programs) [SRC-080](https://www.fao.org/4/ah806e/AH806E19.htm)
3. **Crossbred** คือสัตว์ที่เกิดจากการผสมพ่อแม่ต่างพันธุ์หรือต่างสายตามแผนการผสม การผสมข้ามใช้เพื่อรวมแหล่งพันธุกรรมและอาจใช้ประโยชน์จาก heterosis แต่ผลลัพธ์ขึ้นกับคู่ผสมและระบบ [SRC-079](https://www.canr.msu.edu/resources/swine_breeding_systems_for_alternative_pork_chains_breeding_programs) [SRC-080](https://www.fao.org/4/ah806e/AH806E19.htm)
4. **Line** คือกลุ่มย่อยภายในพันธุ์หรือประชากรที่มีประวัติการคัดเลือก/ขยายพันธุ์เฉพาะ ส่วน **strain** และ **population** อาจใช้ต่างกันตามองค์กรและงานวิจัย จึงต้องอ่านนิยามของแหล่งนั้นก่อนเทียบกัน [SRC-080](https://www.fao.org/4/ah806e/AH806E19.htm) [SRC-081](https://pubmed.ncbi.nlm.nih.gov/28805893/)
5. **Phenotype** คือผลที่สังเกตหรือวัดได้ของสัตว์ เช่น การเติบโตหรือจำนวนลูก ส่วน **genetic potential** คือศักยภาพที่เกี่ยวกับพันธุกรรมซึ่งจะแสดงออกมากน้อยเพียงใดขึ้นกับ environment, nutrition, health และ management; งานทบทวน purebred-crossbred ระบุ genotype-by-environment interaction เป็นองค์ประกอบหนึ่งของความสัมพันธ์ระหว่าง performance สองกลุ่ม [SRC-081](https://pubmed.ncbi.nlm.nih.gov/28805893/)
6. **Heterosis หรือ hybrid vigor** คือความแตกต่างด้าน performance ของลูกผสมเมื่อเทียบกับค่าเฉลี่ยของพ่อแม่พันธุ์แท้ที่ใช้เป็นฐานเปรียบเทียบในระบบนั้น ไม่ใช่คุณสมบัติของพันธุ์เดี่ยว [SRC-079](https://www.canr.msu.edu/resources/swine_breeding_systems_for_alternative_pork_chains_breeding_programs)
7. MSU Extension แยก **individual heterosis** ที่เกิดกับตัวลูกผสมออกจาก **maternal heterosis** ที่เกี่ยวข้องกับสมรรถนะของแม่ลูกผสมและผลต่อรุ่นลูก [SRC-079](https://www.canr.msu.edu/resources/swine_breeding_systems_for_alternative_pork_chains_breeding_programs)
8. การผสมกลับ (**backcross**) คือการนำลูกผสมกลับไปผสมกับพันธุ์/สายที่มีบรรพประวัติร่วมบางส่วน และโดยหลักการอาจลดระดับ heterosis เมื่อเทียบกับการผสมที่พ่อแม่มีความแตกต่างมากกว่า [SRC-079](https://www.canr.msu.edu/resources/swine_breeding_systems_for_alternative_pork_chains_breeding_programs)
9. FAO ระบุว่าการออกแบบ breeding program ต้องพิจารณาวัตถุประสงค์การคัดเลือก ประชากรที่มีอยู่ ตลาด การปรับตัวต่อภูมิอากาศ และโรค/ปรสิตในพื้นที่ ไม่ควรใช้รูปแบบเดียวกับทุกภูมิภาค [SRC-080](https://www.fao.org/4/ah806e/AH806E19.htm)
10. งานวิจัยเกี่ยวกับ heterozygosity ในสุกรพบว่าทิศทางและขนาดความสัมพันธ์แตกต่างกันระหว่าง maternal traits, production traits, meat/slaughter quality traits และระหว่างพันธุ์ จึงไม่สนับสนุนการกล่าวว่า crossbred ดีขึ้นทุกลักษณะเสมอ [SRC-082](https://pubmed.ncbi.nlm.nih.gov/30819106/)
11. การประเมิน purebred และ crossbred ต้องระบุ population, line, sex, environment, nutrition/management system, trait definition และช่วงเวลาวัด เพราะความสัมพันธ์ระหว่าง purebred performance กับ crossbred performance ไม่จำเป็นต้องเท่ากับหนึ่ง [SRC-081](https://pubmed.ncbi.nlm.nih.gov/28805893/)
12. แหล่งไทยของกรมปศุสัตว์และมหาวิทยาลัยแม่โจ้แสดงว่ามีงานปรับปรุงพันธุ์และประเมินสุกรลูกผสมในบริบทไทย แต่ผลของงานเฉพาะประชากรไม่ควรถูกยกระดับเป็นคุณสมบัติสากลของพันธุ์ [SRC-083](https://e-wichakarn.dld.go.th/) [SRC-084](https://rae.mju.ac.th/wtms_documentDownload.aspx?id=MTc0NzE=)

## INTERPRETATION

1. คำว่า “พันธุ์แท้” อธิบายสถานะของระบบ pedigree/breeding program มากกว่าการรับประกัน performance ของสัตว์ทุกตัว
2. คำว่า “ลูกผสม” บอกที่มาจากการผสม ไม่ได้บอกโดยตัวมันเองว่าควรใช้เป็นแม่พันธุ์ สายพ่อ หรือสุกรตลาด การใช้ต้องอ้างอิงวัตถุประสงค์ของระบบ
3. Heterosis เป็นผลของการเปรียบเทียบภายใต้ฐานและเงื่อนไขที่กำหนด จึงไม่ควรใช้เป็นคำโฆษณาว่าลูกผสม “ดีกว่า” ในทุก trait
4. การเห็น phenotype สูงในฟาร์มหนึ่งยังไม่เพียงพอที่จะสรุป genetic potential สูง เพราะ environment และ management อาจเป็นส่วนสำคัญของผลที่เห็น

## PRACTICAL IMPLICATION

1. ก่อนซื้อพ่อแม่พันธุ์ ให้ขอ pedigree/line designation, วิธีบันทึก และนิยามของ breeding program ไม่ใช้สี รูปร่าง หรือชื่อทางการค้าเป็นหลักฐานเดียว
2. เมื่อบันทึกลูกผสม ให้ระบุพ่อ พันธุ์/สายของพ่อ แม่ พันธุ์/สายของแม่ รุ่นการผสม และวัตถุประสงค์การใช้ เพื่อให้ตรวจสอบย้อนกลับได้
3. เมื่อเปรียบเทียบ ADG, FCR, จำนวนลูก หรือคุณภาพซาก ให้บันทึกเพศ ช่วงน้ำหนัก อาหาร สุขภาพ สภาพอากาศ ระบบโรงเรือน และสูตรการคำนวณ
4. เลือกคำว่า purebred, crossbred, maternal line หรือ terminal line ให้ตรงกับระบบจริง และอย่าใช้คำเหล่านี้แทนกัน

## UNCERTAINTY

1. ไม่มีนิยามเดียวที่ใช้เหมือนกันทุกองค์กรสำหรับ breed, line, strain และ population; ต้องระบุผู้กำหนดนิยามและ breeding program
2. แหล่งไทยที่ค้นพบหลายรายการเป็นบทคัดย่อหรือเอกสารที่เข้าถึงข้อความได้จำกัด จึงยังไม่ใช้ตัวเลขจากแหล่งเหล่านั้นเป็น benchmark
3. ค่า heterosis และผลต่างของ purebred/crossbred ขึ้นกับฐานเปรียบเทียบ trait และสภาพแวดล้อม จึงไม่กำหนดช่วงเปอร์เซ็นต์ในหัวข้อนี้
4. คำว่า “ทนร้อน”, “แข็งแรง” หรือ “โตเร็ว” ต้องมี trait และวิธีวัดรองรับ ไม่ควรใช้เป็นคุณสมบัติประจำพันธุ์โดยไม่มีหลักฐาน

## Numeric-claim decision

ไม่มีตัวเลข benchmark ในหัวข้อนี้ แม้ SRC-079 จะมีตารางตัวอย่าง heterosis และ performance เพราะตัวเลขดังกล่าวผูกกับ breed combination และ production system ของเอกสารต้นทาง
