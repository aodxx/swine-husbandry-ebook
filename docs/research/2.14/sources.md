## Source evaluation

S214-01 เป็นงานวิจัย peer-reviewed จาก commercial crossbred population และเข้าถึง abstract เต็ม; ใช้ตัวเลขเฉพาะเพื่อแสดงว่าความสัมพันธ์ขึ้นกับประชากร ไม่ใช้เป็น benchmark ไทย

S214-02 เป็น peer-reviewed open-access study ใน Duroc population; ให้รายละเอียดวิธีวัดและย้ำว่าความสัมพันธ์ต้องประเมินในประชากรเดียวกัน/ระบบเดียวกัน

S214-03 เป็นแหล่งมหาวิทยาลัยที่สรุปการใช้ real-time ultrasound สำหรับ IMF; ใช้เป็นแนวทางวิธีวัด ไม่ใช่ค่ามาตรฐาน

S214-04 เป็น technical reference ของ North Carolina State research; ใช้เพื่ออธิบายเศรษฐศาสตร์และข้อจำกัดของการวัดคุณภาพเนื้อในฟาร์ม
