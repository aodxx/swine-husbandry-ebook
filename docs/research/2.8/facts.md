# Fact List — 2.8 สายแม่และสายพ่อ

วันที่สกัด: 2026-08-23

## FACT

1. ระบบ terminal cross ใช้สายที่มี genetic merit ด้าน reproduction เป็นฝั่งแม่ และสายที่มี merit ด้าน production traits เป็นฝั่งพ่อ เพื่อใช้ความแตกต่างของสายอย่างเป็นระบบ [SRC-110] [SRC-111]
2. Reproductive traits เช่น fertility และ litter size แสดงในสัตว์สืบพันธุ์ ขณะที่ growth, feed efficiency และ carcass traits แสดงในสุกรตลาดและสัตว์ทดแทน [SRC-111]
3. Purebred performance อาจทำนาย crossbred performance ได้ไม่สมบูรณ์เมื่อสภาพแวดล้อมและ genetic correlation แตกต่างกัน จึงมีการพัฒนา terminal-cross model ที่ใช้ข้อมูลลูกผสม [SRC-112]
4. Paternal component ไม่ควรถูกละเลยใน traits ของการสืบพันธุ์ เพราะ boar มีผลทั้งด้าน biological และ genetic ต่อผลของแม่พันธุ์ [SRC-113]
5. MSU อธิบาย terminal, rotational และ rota-terminal systems เป็นระบบที่ต้องเลือกให้สอดคล้องกับ management และ target market [SRC-110]

## INTERPRETATION

maternal line และ terminal line เป็นบทบาทใน breeding system ไม่ใช่ชื่อ breed ที่ตายตัว พันธุ์เดียวอาจถูกใช้ต่างบทบาทในคนละโปรแกรม และ line เดียวอาจมีเป้าหมายการคัดเลือกเฉพาะ

## PRACTICAL IMPLICATION

ฟาร์มควรบันทึกสายพ่อ สายแม่ พ่อแม่ของลูกสุกร ระบบผสม และเป้าหมาย trait แยกจากข้อมูลที่ฟาร์มวัดจริง ไม่ใช้ชื่อพันธุ์แทนข้อมูล line

## UNCERTAINTY

ตัวอย่างระบบจากสหรัฐฯ และฝรั่งเศสไม่ใช่สูตรสำเร็จของฟาร์มไทย และไม่มีตัวเลข benchmark ในหัวข้อนี้
