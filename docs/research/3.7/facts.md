# Fact List — 3.7 Wean-to-finish

วันที่สกัด: 2026-08-23

## FACT
1. Wean-to-finish คือระบบที่รับสุกรหลังหย่านมแล้วเลี้ยงต่อในสถานที่/flow เดียวจนถึงช่วงขาย ลดการย้ายระหว่าง nursery และ finishing เมื่อเทียบกับระบบแยกช่วง [S307-03]
2. การลดการย้ายโรงเรือนอาจลดการผสมฝูงและขั้นตอนขนย้าย แต่ไม่ได้ลบความเสี่ยงจากแหล่งสุกร คน รถ อุปกรณ์ และการจัดการ [S307-03] [S307-04]
3. ฟาร์มยังต้องจัดการอาหาร น้ำ อุณหภูมิ พื้นที่ สุขภาพ สวัสดิภาพ ของเสีย และบันทึกตามข้อกำหนดที่เกี่ยวข้อง [S307-01] [S307-02]
4. ระบบนี้ต้องออกแบบอาคารให้รองรับการเปลี่ยนขนาดสุกรและทำความสะอาด/ระบายออกได้ [S307-03]

## INTERPRETATION
Wean-to-finish อาจลดความซับซ้อนจากการย้ายช่วง แต่เพิ่มความต้องการด้านการออกแบบอาคารและการจัดการสัตว์ต่างวัยภายในระบบเดียว.

## PRACTICAL IMPLICATION
ตรวจว่ามีพื้นที่และอุปกรณ์ที่ปรับตามวัยได้ มีแผนรับสุกรกลุ่มเดียว ทำความสะอาด และขาย/ระบายโดยไม่เกิดค้างคอก.

## UNCERTAINTY
ผลต่อสุขภาพและเศรษฐศาสตร์ขึ้นกับการออกแบบอาคาร flow แหล่งสุกร อาหาร และการจัดการจริง; ไม่มีคำตอบเดียวสำหรับทุกฟาร์ม.
