# Draft Notes — 1.11 คำศัพท์พื้นฐานที่คนเลี้ยงหมูต้องรู้

วันที่ร่าง: 2026-08-23
สถานะ: DRAFTED

## Editorial decisions

เลือกคำศัพท์แกนกลางจำนวนจำกัดเพื่อไม่ให้หัวข้อกลายเป็นพจนานุกรมทั้งเล่ม แบ่งเป็นคำเรียกสุกร ระยะการผลิต การจัดการ flow และตัวชี้วัด ใช้คำอังกฤษกำกับเมื่อจำเป็น และเตือนคำที่มีนิยามต่างกันตามบริบท

## Claim map for fact check

- boar, barrow, gilt, sow, piglet, litter, farrowing, gestation, lactation, nursery, grow-finish และ farrow-to-finish: ตรวจตรงกับ EPA/USDA
- AIAO, batch, group, cohort และ multi-site: ตรวจตรงกับ EPA, Pork Gateway, UMN และ Frontiers โดยไม่ถือเป็นคำพ้องสมบูรณ์
- born alive, stillborn, mummies, mortality และ culling: ตรวจตรงกับ WOAH ในระดับนิยาม/ตัวชี้วัด ไม่ให้คำแนะนำสุขภาพ
- ADG และ FCR: อธิบายความหมายเชิงแนวคิดและเงื่อนไขการเปรียบเทียบ ไม่ใส่สูตรหรือตัวเลข benchmark ที่ยังไม่มี source เฉพาะใน workspace
- practical implications: ระบุเป็นข้อเสนอเชิงบรรณาธิการของตำรา ไม่อ้างว่าเป็นข้อกำหนดจาก Source

## Out-of-scope check

ไม่มีการวินิจฉัยโรค เลือกยา วัคซีน หรือการรักษา และไม่มีประวัตินิพนธ์ฟาร์ม จึงไม่เปิดคำแนะนำ high-risk แต่คำศัพท์สุขภาพถูกจำกัดไว้ที่นิยามและมีคำเตือน
