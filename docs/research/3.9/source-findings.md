# Source Findings — 3.9 เงินลงทุนเริ่มต้น

วันที่ตรวจ: 2026-08-23

1. มกอช. มีเอกสารทางการ มกษ. 6403-2565 เรื่องการปฏิบัติทางการเกษตรที่ดีสำหรับฟาร์มสุกร ใช้เป็นกรอบรายการสถานที่ โรงเรือน การจัดการ สุขภาพ สวัสดิภาพ สิ่งแวดล้อม และบันทึก ไม่ใช่ราคาก่อสร้าง.
2. กรมปศุสัตว์มีหน้า “ราคาเฉลี่ยสินค้าปศุสัตว์” ซึ่งยืนยันว่าราคาสินค้าปศุสัตว์เผยแพร่เป็นรายช่วงเวลาและต้องตรวจวันที่ก่อนใช้อ้างอิง. หน้านี้ไม่ใช่บัญชีราคาก่อสร้างหรือใบเสนอราคาของฟาร์ม.
3. สำนักพัฒนาอาหารสัตว์ กรมปศุสัตว์มีบริการสูตรอาหารสัตว์ แต่สูตรอาหารไม่ใช่ราคาวัตถุดิบและไม่ควรใช้สร้างต้นทุนปัจจุบันเอง.
4. หลักการเขียนหัวข้อนี้จึงใช้รายการต้นทุนและสูตรเท่านั้น; ราคาจริงต้องขอใบเสนอราคาตามสถานที่ แบบอาคาร ขนาด ระบบ และวันที่ลงทุน.
