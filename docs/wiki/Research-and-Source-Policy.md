# Research & Source Policy

## Source hierarchy

### Tier A — Thai official / primary
- กรมปศุสัตว์ (DLD)
- สถาบันสุขภาพสัตว์แห่งชาติ (NIAH)
- กฎหมาย/มาตรฐาน/หน่วยงานรัฐไทย
- มหาวิทยาลัยไทยที่มีเอกสารวิชาการที่ตรวจสอบได้

### Tier B — International standards
- WOAH
- FAO
- WHO
- Codex

### Tier C — Academic / extension
- peer-reviewed journals
- veterinary schools
- agricultural extension
- textbooks / technical manuals

### Tier D — Supplementary industry sources
ใช้เป็นบริบทหรือคำศัพท์เท่านั้นเมื่อไม่มีแหล่งที่ดีกว่า และต้องระบุข้อจำกัด

## ไม่ใช้เป็น primary source
- blog ทั่วไป
- SEO content
- social media
- forum
- แหล่งไม่ทราบผู้รับผิดชอบ
- AI answer ที่ไม่มีหลักฐานต้นทาง

## Numeric claims
ตัวเลขทุกค่าที่มีผลต่อการตัดสินใจต้อง:

1. มี source ID ที่ resolve ได้ หรือ
2. ระบุชัดว่า `EXAMPLE_ONLY`

ห้ามนำ benchmark ต่างประเทศมาใช้เป็นมาตรฐานไทยโดยตรงโดยไม่มีบริบท

## High-risk topics
หัวข้อเหล่านี้ต้อง review เพิ่ม:

- โรค
- วัคซีน
- ยา
- antimicrobial use
- outbreak response
- euthanasia

เนื้อหาต้องแยก:

`Observation → Prevention → Biosecurity → First management → Confirmation → Treatment`

ไม่สั่งยาและไม่ให้ dose เฉพาะราย

## Farm history evidence rule
เรื่องราวของนิพนธ์ฟาร์มต้องมาจากหลักฐานจริงเท่านั้น เช่น ภาพเก่า เอกสาร บิล สมุดบันทึก หรือคำบอกเล่าที่ระบุผู้ให้ข้อมูลและความไม่แน่นอนได้

ถ้ายังไม่มีหลักฐานให้ใช้ `PENDING_FARM_HISTORY` ห้ามเติมช่องว่างด้วยการคาดเดา
